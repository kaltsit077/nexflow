# 功能接口与布局（第一性原理）

> 一条产品链路 = 一块界面区域 = 一组 runner 接口。禁止同功能多套样式/多套入口。

---

## 1. 产品只有三条链路

```text
[获取脚本] 导入 / 游戏目录 / 编辑里录制导出后仍属该脚本
      ↓
[编排队列] 脚本库 → 加入队列 → 调序 / 队列参数
      ↓
[执行监控] 运行选中队列 → 日志 / 停止 / 历史
```

| 链路 | 界面落点 | runner 接口（唯一） |
|---|---|---|
| 获取 | 顶栏工具；脚本「编辑」②录制页 | `catalog.detect_tool` · `tool_installer.install_tool` · `pipeline_recorder.export_pipeline`（写 PI，不写 config） |
| 编排 | 中栏左队列 + 右脚本库 | `config.load/save` 读写 `scripts[]` / `lists[]`；脚本行「目录」→ `resolve_script_dir` |
| 执行 | 底栏；脚本行「启动」 | `executor.run_list` / `run_single_script` · `append_history` |

录制/连控试跑走 `maa_runtime.MaaSession`（嵌在 `ScriptEditorDialog`），**不**走 `run_list`（调度与试跑是两条路径，禁止混成一套 API）。

---

## 2. 接口一览（一对一）

### 2.1 配置 `runner/config.py`

| 接口 | 职责 |
|---|---|
| `load_config` / `save_config` | 唯一读写 `config.json` |
| `load_history` / `append_history` | 唯一读写 `history.json` |
| `resolve_script_dir` | 脚本对应的项目/工作目录（打开资源管理器用） |
| `ensure_runtime_files` | 种子目录/示例配置 |
| `prune_run_logs` | 日志裁剪 |

UI **不得**另写一套 JSON I/O。

### 2.2 调度 `runner/executor.py`

| 接口 | 职责 |
|---|---|
| `run_single_script` | 跑一个 script dict |
| `run_list` | 跑选中队列：`mode=sequential` 逐步；`parallel` 按 `lane`/`max_parallel` 有限并发 |
| `make_stop_flag` | 协作停止 |
| `RunnerCallbacks` / `StepResult` | 进度与结果 |

命令拼装只经 `_build_command` → `maafw.build_maafw_command`（`type=maafw`）。

### 2.3 识别与 preset `runner/catalog.py`

| 接口 | 职责 |
|---|---|
| `detect_tool` | 路径 → 脚本草稿 |
| `apply_preset` | 合并 preset 到 script |

### 2.4 安装 `runner/tool_installer.py` + `tool_catalog.py` + `library.py`

| 接口 | 职责 |
|---|---|
| `tool_catalog.list_tools` | 目录元数据 |
| `install_tool` / `scan_and_register` | 下载解压并登记 |
| `library.*` | `library/<id>/app` 布局 |
| `github_auth.*` | Token 读写（`.github_token` / 环境变量）；安装 API 带 `Authorization` |

### 2.5 录制/连控 `runner/maa_runtime.py` + `pipeline_recorder.py` + `process_launch.py`

| 接口 | 职责 |
|---|---|
| `ensure_library` / `list_windows` / `list_adb_devices` | 进程内 Maa |
| `MaaSession` | 连接 / 截图 / 试跑 |
| `export_pipeline` | 录制 → PI 文件 |
| `process_launch.launch_detached` / `run_pre_launches` | 录控启动；脚本 `pre_launch[]` 前置拉起；Windows 默认 `runas` 管理员 |
| `after_launch.run_after_launch` | `wait_mode=launch` 后按窗口过滤执行点击；支持单点或 `steps[]` 多步 |

可选脚本字段（仅方便录控，不影响 `MaaPiCli` 调度）：`studio_launch` / `studio_launch_workdir` / `studio_launch_settle_sec`。

UI 唯一入口：`ui/script_editor.py` 页签「② 录制/连控」；**禁止**再挂顶栏独立「工作室」按钮。

### 2.6 已废弃（勿接新调用）

| 模块 | 原因 |
|---|---|
| `runner/screencap.py` | 预览已统一 `maa_runtime` |

## 3. 界面分区（功能 = 布局）

固定间距：`GAP = 12`（区与区之间只留这一档，不叠多层小卡片边距）。

```text
┌─ 顶栏 TOOLS（获取）────────────────────────────┐
│ Game Runner    主题▾   导入 游戏目录 历史       │
├─ 中栏 COMPOSE ─ GAP ─ LIBRARY ────────────────┤
│ 队列（折叠/加入目标） │ 脚本库（筛选/加入/拖拽） │
├─ 底栏 RUN（执行）─────────────────────────────┤
│ 状态 · 日志              停止 | 运行选中队列   │
└───────────────────────────────────────────────┘

脚本「编辑」一窗：① 路径与调度（无启动后点击）  |  ② 连控/录制
  ②：上=连接条（高级可折）· 下左=步骤 · 下右=实时截图占满剩余 · 底=日志可折
步骤「队列参数」：仅 retry / on_fail / preset / fallback
```

| 区 | 有 | 没有 |
|---|---|---|
| TOOLS | 导入、游戏目录、历史、主题（`ui.theme` → 内置调色板） | 独立工作室、运行、加入步骤 |
| COMPOSE | 新建/改名/删队列、模式(顺序/并行)/max_parallel、步骤▲▼、**编辑**（同脚本库一窗，含 lane）、**队列参数**、选中目标 | 第二套「运行」 |
| LIBRARY | 加入、**编辑（含录制）**、拖拽、目录、启动 | 日志、队列运行 |
| RUN | 唯一队列运行入口、停止、日志 | 脚本编辑 |

同功能禁止两套样式：脚本行 = 扁平列表；步骤 = 队列内卡片（仅此一处卡片）。

### 3.1 弹窗约定

| 约定 | 做法 |
|---|---|
| 尺寸 | 一律 `ui/dialog_chrome.fit_dialog`（夹在屏幕 availableGeometry 内，可拖角缩放） |
| 边距 | `dialog_margins` = `PAD`/`GAP`（与主台一致） |
| 稠密页 | 正文用 `scroll_page`；**底栏放滚动区外** |
| 底栏 | 大窗用 `footer_bar(..., add_close=True)`；主操作 `objectName=primary` |
| 样式 | 共用 `styles.app_stylesheet`；说明文案 `muted` |
| 小表单 | 可用 `QDialogButtonBox`（如队列参数确定/取消） |

## 4. 数据流（禁止来回倒）

```text
磁盘 config.json
    ↕  load/save（MainWindow 持有一份 self.cfg）
UI 只改 self.cfg 字段 → save
执行时 RunnerWorker 拿 cfg 快照 → run_list（不再经 UI 改写）
历史只 append_history，不回流改 lists
```

反模式（已避免 / 勿引入）：

- UI 与 runner 各缓存一份 scripts 不同步  
- 为「方便」再包一层 ScriptService / QueueService（当前体量用 MainWindow 编排即可）  
- 队列运行又走工作室 `MaaSession`

## 5. 架构气味（已知，按优先级）

| 气味 | 处理 |
|---|---|
| `screencap.py` 死代码 | 保持废弃，勿接线 |
| `numpy_to_qimage` 在 runner | 历史例外；勿再扩大 Qt 进 runner |
| 顶栏与底栏曾各有「运行」 | **已收敛到底栏唯一运行** |
| 顶栏「工作室」与脚本「编辑」职责重叠 | **已合并：编辑一窗含录制；顶栏无工作室** |
| 「配置」语义模糊（脚本 vs 步骤） | **步骤改名「队列参数」；脚本改用「编辑」** |
| 脚本卡与步骤卡长得像 | **已区分：库=扁平行，步骤=卡片** |
| `_refresh_all` 过重整树重建 | 可接受；勿再拆虚拟列表除非列表 >100 |
